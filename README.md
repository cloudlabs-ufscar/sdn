# Open-Source Network Virtualization & SDN Training 

This repository is a comprehensive technical guide and workspace for developing solid expertise in **Software-Defined Networking (SDN)**. The focus is on the industry-standard stack: **Open vSwitch (OVS)** and **Open Virtual Network (OVN)**.

Our goal is to bridge the gap between basic Linux networking and complex cloud infrastructure, enabling engineers to design, implement, and maintain high-performance virtual networks.

##  Repository Organization

The repository is structured into two main areas to support both learning and advanced engineering:

### 1. Training Section
A modular, step-by-step learning path. Each module includes theoretical documentation, a practical laboratory, and an **automation script** to provision the environment (VMs, Bridges, Namespaces) instantly.

### 2. Projects Section
Advanced, open-ended implementations based on a **Technical Work Plan**. These projects simulate real-world cloud scenarios, including multi-datacenter interconnection, SRE observability stacks, and active open-source contributions to the OVN core.

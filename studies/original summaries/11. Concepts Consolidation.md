## Bridge x Logical Switch e Logical Router

- Logical Switch e Logical Router representam a topologia e o comportamento lógico da rede. O `ovn-controller` traduz essa lógica em configurações/flows do OVS, que então realiza o forwarding efetivo, localmente ou através de túneis como GENEVE. A Bridge atua em um nível mais físico, onde o direcionamento de pacotes entre máquinas passa por ela. 
## OVS Bridge x Linux Bridge

- A Linux Bridge é criada diretamente pelo kernel Linux, ao executar comandos como:
	`$: ip link add br0 type bridge`
	`$: ip link set eth0 master br0`
	Funcionando como um switch Ethernet L2 tradicional: Aprende MACs e encaminha pacotes para a porta correta

- A OVS Bridge é uma bridge criada pelo Open vSwitch, ao executar comandos como:
	`$: ovs-vsctl add-br br int`
	`$: ovs-vsctl add-port br-int ...`

A grande diferença é que o OVS foi projetado para ser um switch virtual programável, especialmente para ambientes de virtualização e SDN. Portanto, a Linux Bridge é mais limitada por não oferecer o suporte OpenFlow, OVSDB, integração com OVN e mais.

## TUN/TAP e VETH

- **VETH** - Virtual Ethernet. É um par de interfaces Ethernet virtuais ligadas diretamente uma à outra. Muito usado com network namespaces. Por exemplo:
	`$: ip link add veth-host type veth peer veth-ns`
	`$: ip link set veth-ns netns ns1` 

- **TAP** - Também é uma interface virtual Ethernet, mas a ideia é diferente. Ele cria uma interface que permite que um programa no userspace leia/escreva frames Ethernet (L2). Permite que um programa participe diretamente do tráfego Ethernet. Abordando mais profundamente, o outro lado da interface é um file descriptor em userspace (`/dev/net/tun`). É como o QEMU/KVM conectam uma VM: o vhost-net ou o próprio QEMU lê/escreve no `fd`.  

- **TUN** - Parecido com o TAP, mas atua em uma camada diferente. O TUN atua em pacotes IP (L3).

Fazendo um comparativo: 

| **Interface** | **Transporte**       | Ligação Típica                     |
| ------------- | -------------------- | ---------------------------------- |
| **VETH**      | Ethernet Frames (L2) | Interface ↔ Interface              |
| **TAP**       | Ethernet Frames (L2) | Kernel ↔ Programa Userspace (QEMU) |
| **TUN**       | IP Packets (L3)      | Kernel ↔ Programa Userspace (QEMU) |

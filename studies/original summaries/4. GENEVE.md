
- O GENEVE (Generic Network Virtualization Encapsulation) é um protocolo de encapsulamento que tem a habilidade de encapsular qualquer tipo de tráfego de rede.  

- O OVS possui alguns tipos de interfaces que usamos:
	1. **Normal** - É um tipo de interface que possibilita montar uma NIC física do OVS do host no OVS.
	2. **Internal** - É um tipo de interface virtual criada pelo OVS utilizada para conectar workloads.
	3. **Patch** - Quando existem diferentes bridges gerenciadas pelo OVS, é possível criar conectividade entre elas usando a Patch Port. O tráfego de rede recebida por uma patch port de uma bridge é encaminhado para outra via patch port.
	4. **Tunnel** -  É utilizado para criar uma rede virtual em cima do underlay e possibilitando tráfego de rede L2. Tunneling permite que bridges em diferentes hosts possam ter conectividade, como se estivessem no mesmo host
